📖 読解・完全攻略

応用試験の読解は「文章を読む試験」ではなく「場面を分析して最適解を選ぶ試験」
設問・対象者・目的・授業条件を先に押さえ、本文の根拠と教育的妥当性を組み合わせる。
① 設問を先に読む
「最も適切」「誤っている」「必要ない」「まず行うべき」など、何を選ぶ問題かを確認する。
② 場面を整理する
学習者のレベル・目的・母語・課題／教師の目的・授業段階／教材・時間・人数を拾う。
③ 根拠を探す
しかし・一方・つまり・そのため・例えば・これに対して、などの接続表現に注目。主張・理由・具体例・結論を分ける。

🔍 読解の2つの処理

トップダウン
既有知識・文脈・予測・スキーマを使って全体像から理解する。
ボトムアップ
文字→語→文→段落と、小さい単位を積み上げて理解する。
応用試験では両方
まず全体を予測し、必要な箇所だけ精密に読む。全部を同じ濃さで読まない。

📚 よく出るキーワード

スキミング全体の要点を素早く把握する。
スキャニング日時・数字・固有情報など特定情報を探す。
推論本文に直接書かれていない内容を根拠から推測する。
モニタリング自分の理解を確認・修正する。
結束性指示詞・接続詞・照応など、文と文をつなぐ仕組み。
一貫性文章全体が意味的にまとまっていること。

🎯 選択肢の見抜き方

「いつも・必ず・すべて・絶対」→ 強すぎないか確認。
本文にない知識→ 常識では正しくても本文の根拠がなければ注意。
一部だけ正しい→ 条件が抜けていないか確認。
目的と手段の逆転→ 「活動そのもの」が目的になっていないか確認。

🧑‍🏫 授業場面の読み方

① 学習者が何に困っている？ → ② 教師は何を目標にしている？ → ③ 今は授業のどの段階？ → ④ その活動は目標に合う？ → ⑤ 次に何をするのが最適？
迷ったら
「学習者にとって有効か」「授業目標に合うか」「場面に適切か」の3点で比較する。

🎧 聴解・完全攻略

聞こえた瞬間に「用語」を当てない。
①何が違う？ → ②どの領域？ → ③専門用語 → ④選択肢、の順で処理する。

⏱ 5秒分類

テンス＝「いつ？」
昨日、映画を見ます。→過去なのに現在形 → テンス
アスペクト＝「動作はどう進んでいる？」
もう宿題をしています／もう宿題をしましたなど、完了・継続・開始などを見る。
ヴォイス＝「誰がする？誰が影響を受ける？」
私は先生を褒められました。→受身・使役などの関係。
モダリティ＝「話し手はどう判断・態度を示す？」
でしょう・かもしれない・はずだ・に違いない等。
格・格助詞＝「誰が・誰に・何を・どこへ？」
学校を行きます。→「に」など、名詞と述語の関係。
待遇・語用＝「この相手・場面に合う？」
文法的に正しくても、依頼・断り・謝罪などで不適切なことがある。
音声・音韻＝「音そのもの？」
長音・促音・撥音・アクセント・清濁・調音点・調音法など。
語彙・意味＝「語の意味・使い方・共起？」
コロケーション、類義語、多義語、メタファー、メトニミーなど。

👂 聞き取りのチェック順

① 学習者の発話をそのまま聞く → ② 正しい形を頭に置く → ③ 差を1か所に絞る → ④ 文法／音声／語彙／語用に分類 → ⑤ 選択肢の用語と一致させる。

🗣️ 教師の応答も聞く

直接訂正：誤りをすぐ示す。
明示的フィードバック：何が誤りか明確に示す。
リキャスト：学習者の誤りを正しい形に言い換えて返す。
明確化要求：「もう一度お願いします」など、伝達上の問題を示す。
誘導・ヒント：学習者自身に修正させる。

長音「おばさん／おばあさん」・促音「きて／きって」・撥音「しんぶん」・拗音「きや／きゃ」・アクセント・無声化・清音／濁音・拍（モーラ）。

👄 口腔断面図・音声 完全版

音声問題は「音→どこで→どう作る→用語」の順。
口腔断面図では、調音点と調音法をセットで見る。
【国試対策】口腔断面図・番号から名称を答える
まず番号で覚える： 1鼻腔　2上の歯・歯茎　3口腔前方　4舌尖　5舌端　6舌面　7口蓋垂　8咽頭　9喉頭　10声門・声帯付近　11硬口蓋　12軟口蓋
⚠️ 実際の試験では、図がもっと簡略化され、部位名ではなく番号だけが示されることがあります。
→「図を見る → 調音点を判断 → 音を結び付ける」の練習を優先。

🦷 口腔断面図で覚える場所

前から順に
上唇・下唇 → 歯 → 歯茎 → 硬口蓋 → 軟口蓋 → 口蓋垂 → 咽頭 → 喉頭 → 声帯・声門。
舌の部位
舌尖（舌の先）／舌端（先端に近い部分）／舌面（中央・広い面）／舌根（奥の部分）。

📍 調音点

両唇音：唇で作る → ぱ・ば・ま
歯茎音：歯茎付近 → た・だ・な・ら・さ・ざ
硬口蓋付近：硬口蓋付近 → き・ぎ・に・ひ等
軟口蓋音：軟口蓋付近 → か・が等

🔧 調音法

破裂音：閉鎖→圧力→一気に開放。
摩擦音：狭い隙間を通して摩擦を起こす。
破擦音：破裂＋摩擦。
鼻音：鼻腔へ空気を通す。
弾き音：舌先などを一度弾く。

🔊 声の仕組み

声帯：振動して有声音を作る。
声門：声帯の間のすき間。
有声音：声帯が振動。
無声音：基本的に声帯が振動しない。

🎵 日本語の音声用語

モーラ（拍）日本語のリズムの基本単位。
長音母音を長く発音する。
促音「っ」に代表される1拍。
撥音「ん」に代表される1拍。
拗音「きゃ・しゅ・ちょ」など。
アクセント音の高低の配置。

🎯 音→用語 練習

「きて」と「きって」の違い → 促音・拍数。
「おばさん」と「おばあさん」 → 長音。
「か」と「が」 → 清濁・声帯振動。
「きゃ」と「きや」 → 拗音・拍構造。

🔤 動詞のグループ・活用

まずここを覚える！
日本語教育では、動詞を「1グループ（五段）・2グループ（一段）・3グループ（不規則）」に分けて考える。活用問題では、まずグループを判断してから形を作る。
① 1グループ＝五段動詞
辞書形の最後の音が、活用によって変化する。
書く→書いて／読む→読んで／話す→話して／買う→買って
② 2グループ＝一段動詞
基本的に「る」を取って、必要な形を付ける。
食べる→食べて／見る→見て／起きる→起きて
③ 3グループ＝不規則動詞
「する」「来る（くる）」が代表。
する→して／来る→来て（きて）

🟦 て形の作り方

1グループ
う・つ・る → って
む・ぶ・ぬ → んで
く → いて
ぐ → いで
す → して
⚠️ 行く→行って（「行いて」ではない）
2グループ
るを取る＋て
食べる→食べて／見る→見て
3グループ
する→して／来る→来て

🟩 ない形

1グループ
最後の「う段」を「あ段」にして＋ない。
書く→書かない／読む→読まない／話す→話さない
⚠️ 「う」はわになる：買う→買わない
2グループ
るを取る＋ない：食べる→食べない／見る→見ない
3グループ
する→しない／来る→こない

🟨 た形

て形の「て・で」を「た・だ」に変える
書いて→書いた／読んで→読んだ／話して→話した／買って→買った

🟥 辞書形に戻す

て形から考えるとき
書いて→書く／読んで→読む／食べて→食べる／して→する／来て→来る

⚠️ 「る」で終わる＝2グループではない！

帰る・入る・走る・切る・知る・要る・作る・取る などは1グループ。
帰る→帰って／入る→入って／走る→走って
⭐ 応用試験での見方
「るで終わるから2グループ」と決めつけない。まず動詞のグループを判定し、次に活用形を考える。学習者の誤用では「どの活用形の、どこが違うのか」を分類する。
🧠 覚え方
て形はまず「うつる・むぶぬ・く・ぐ・す」。
うつる→って／むぶぬ→んで／く→いて／ぐ→いで／す→して
そして例外は行く→行って。

📊 評価・統計・計算

応用試験の見方
「何を評価するか」→「何のためか」→「いつ行うか」→「どんな方法が適切か」の順に考える。数字の計算だけでなく、評価の目的・質・解釈まで問われる。
① 平均値
合計点 ÷ 人数。全員の得点をならして代表させる値。
例：70・80・90 → 80点
② 中央値
得点を小さい順に並べたとき中央にくる値。極端に高い・低い値の影響を平均値より受けにくい。
例：60・70・75・80・100 → 中央値75
③ 最頻値（モード）
最も多く現れる値。
例：60・70・70・80 → 最頻値70
④ 範囲（レンジ）
最大値 − 最小値。得点のばらつきを簡単に見る指標。
⑤ 得点率・正答率
得点 ÷ 満点 × 100。
例：42点／50点 → 84％
⑥ 分散・標準偏差
分散は得点のばらつきを数値化したもの。標準偏差は分散の平方根で、元の得点と同じ単位でばらつきを表す。
標準偏差が大きい＝得点が平均から広く散らばる。
⑦ 偏差値
平均50・標準偏差10になるように得点を標準化した指標。
一般式：50 ＋ 10×（得点−平均）÷標準偏差
⑧ 妥当性（validity）
「測りたいものを、本当に適切に測れているか」。
例：会話能力を測りたいのに、漢字の筆記問題だけでは目的とのズレが生じる。
⑨ 信頼性（reliability）
測定結果が安定して一貫しているか。偶然の誤差が小さいほど信頼性が高い。
⑩ 客観性
評価者が変わっても判断が大きくぶれにくいこと。明確な評価基準や採点基準が重要。
⑪ 波及効果（washback）
試験・評価が、その後の学習や授業・指導に及ぼす影響。
良い波及効果：実際のコミュニケーションを促す。悪い波及効果：試験に出る知識だけを暗記する。
⑫ 基準準拠評価（criterion-referenced）
あらかじめ定めた到達基準・目標に照らして評価する。「他の学習者より上か」ではない。
⑬ 集団準拠評価（norm-referenced）
集団内での位置や相対的な差を基準に評価する。順位や偏差値などが典型。
⑭ 診断的評価
学習開始前などに、学習者の現在の力・つまずきを把握し、指導計画に生かす。
⑮ 形成的評価
学習の途中で理解度を確認し、フィードバックや指導改善につなげる。「学習のための評価」。
⑯ 総括的評価
学習のまとまりの終わりに、到達度や成果をまとめて判断する。「学習の成果を確認する評価」。
⑰ ルーブリック
評価観点（例：課題達成・構成・文法・語彙・表記）と、段階別の評価基準を表にしたもの。作文・発表・会話などのパフォーマンス評価で活用しやすい。
⑱ 項目分析
テストの各問題が適切に機能しているかを調べる。
難易度：正答率が高いほど「易しい」。識別力：上位群と下位群をどの程度区別できるか。
⑱-1 3群法（上位群・中位群・下位群）
受験者を成績順に分け、問題ごとの正答率を比較して、問題がどの程度学力差を識別できるかを見る。
上位群＝成績の高いグループ／中位群＝中間のグループ／下位群＝成績の低いグループ
例：上位80％・中位50％・下位20％ → 上位ほど正答率が高く、識別が良好と考えやすい。
逆に上位20％・中位50％・下位80％のような逆転は、識別力がマイナスになる可能性があり、問題や選択肢を点検する。
⑲ 自己評価・相互評価
自己評価＝自分の学習を振り返る。相互評価＝学習者同士で評価する。評価基準を共有すると学習目標が明確になる。
⑳ パフォーマンス評価・ポートフォリオ
実際の課題遂行や作品・学習記録をもとに、能力や成長を多面的に評価する。
⭐ 試験でのひっかけ
「妥当性＝結果が安定」ではない → 安定性は信頼性。
「形成的＝最後の試験」ではない → 途中で指導改善に使う。
「基準準拠＝順位」ではない → 到達基準との比較。
「ルーブリック＝点数だけ」ではない → 観点×段階の基準。

📜 ① 日本語教育の推進に関する法律

ポイント
日本語教育の推進に関する基本理念や、国・地方公共団体等の責務、基本的施策の方向性を定める法律。
試験での見方
日本語教育を単なる「学校の授業」だけでなく、外国人等の社会参加・共生に関わる施策として捉える。

🏫 ② 日本語教育機関認定法

正式な位置付け
日本語教育の適正かつ確実な実施を図るため、日本語教育機関の認定等と、認定日本語教育機関で日本語教育を行う者の資格について定める法律。
施行
令和6年4月1日から制度が開始。文部科学大臣が一定の基準を満たす日本語教育機関を認定する。

👩‍🏫 ③ 登録日本語教員

国家資格
日本語教員試験、実践研修、登録などの制度により、専門性を持つ日本語教員を位置付ける。
基本イメージ
日本語教員試験に合格＋登録実践研修機関による実践研修の修了 → 登録日本語教員として登録。

🏢 ④ 認定日本語教育機関

何が認定される？
教職員・施設設備・教育課程など一定の基準を満たし、日本語教育を適正かつ確実に実施できる日本語教育機関を文部科学大臣が認定する。
課程分野
「留学」「就労」「生活」の目的に応じた課程分野がある。目的・対象に応じた教育を考える。

🎓 ⑤ 登録実践研修機関・登録日本語教員養成機関

登録実践研修機関：登録日本語教員に必要な実践研修を実施する機関。
登録日本語教員養成機関：日本語教員に必要な知識・技能を学ぶ養成課程を実施する機関。

⏳ ⑥ 経過措置

制度開始後の移行期間には、一定の要件を満たす現職者等に関する経過措置が設けられている。制度の期限・対象・要件は最新の文部科学省資料で確認する。

🌏 ⑦ 地域日本語教育・多文化共生

生活者・就労者・子どもなど、学習者の目的に応じて日本語教育を捉える。地域社会への参加、行政・学校・医療・職場などとの連携も重要。

🧠 法令問題の覚え方

推進法＝日本語教育を社会全体で推進する基本的枠組み
